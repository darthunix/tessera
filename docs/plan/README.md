# Working plan

`plan-migration.txt` is the project's working log up to 2026-10-04, kept
in Russian: the work item by item, the measurements and findings behind
each choice, the maintainer's decisions with their dates, and what each
item delivered. It is frozen and gets no new entries. It records how the
code came to be; it is not the documentation of the code.

[INDEX.md](INDEX.md) lists its items: a title, whether the item is done,
its lines, and the parts of the system it explains. What the parts
promise and how they are built is in
[`openspec/specs/`](../../openspec/specs); the work the log left open is
the queue in [`openspec/roadmap.md`](../../openspec/roadmap.md); new
work is recorded in `openspec/changes/`. Commit messages up to that date
cite the log's items ("Plan 4.34") where it records their reasons at
length.

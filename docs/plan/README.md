# Working plan

`plan-migration.txt` is the project's working log, kept in Russian: the work
item by item, the measurements and findings behind each choice, the
maintainer's decisions with their dates, and what each item delivered. It
records how the code came to be and what comes next; it is not the
documentation of the code, which is the rest of `docs/` and the code
itself. Commit messages cite its items ("Plan 4.34") where it records their
reasons at length.
